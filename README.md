# ClippedNow.gg website

Promo + install site for the ClippedNow.gg BuildNow GG clipper.

- Static only: `index.html`, `styles.css`, `app.js`. No build step.
- Download buttons point at the Supabase CDN `clippednow.latest.user.js`.
- Deploy: import this repo in Vercel as a static project (no framework, no build command, output directory `.`).

Source of truth for page content lives in the main project repo under `site/`.
